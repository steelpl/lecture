# CE100 · 공학프로그래밍입문

**2026학년도 1학기 주차별 실습 자료**입니다. Python의 기본 원리와 기능을 이해해 코딩 AI에 좋은 질문·지시를 하고, 코드와 결과를 검토하는 능력을 기릅니다.

기존 실습 노트북 14개를 한국어 설명과 작은 실험 중심으로 개편했습니다. [학생 학습 가이드](LEARNING_GUIDE.md)에서 진행 방법을, [교수자 가이드](TEACHING_GUIDE.md)에서 수업 운영과 학습 증거 점검 기준을 확인할 수 있습니다.

## 사용 방법

1. 해당 주차 폴더의 README에서 노트북과 준비 사항을 확인합니다.
2. **Colab에서 열기** 링크로 저장소의 노트북을 엽니다. 본인 Drive에 사본을 저장해 실습합니다.
3. **원리 → 예측 → 실행·변형 → 기능 완성 → AI 제안 검토·수정 지시 → 새 상황 적용** 순서로 진행합니다.
4. 학생 과제의 TODO를 완성하고 공개 점검에 더해 직접 만든 반례를 확인합니다. “미완료” 출력은 점검 통과가 아닙니다.

## 자료 현황

- 원본 파일명과 강의 주제를 유지하고 학습 흐름·예제·과제를 개편했습니다. 원본 Drive 링크, 원본 강의록의 파일명·슬라이드 번호, 개편 전·후 해시는 [자료 목록](materials-manifest.json)에 기록했습니다. 원본 내용은 [개편 전 커밋](https://github.com/steelpl/lecture/tree/89e38ea511ab48aab84268d346729a7b1392093a/CE100-engineering-programming)에서 확인할 수 있습니다.
- 예제는 외부 데이터 다운로드와 개인 Drive 연결 없이 실행할 수 있도록 구성했습니다. 파일 실습은 임시 폴더를, 분석은 명시적으로 표시한 합성 데이터를 사용합니다.
- 각 노트북에는 미완성 학생 과제, 공개 점검, 검토용 가상 AI 답변, 요청문·수정 지시·반례 기록란이 있습니다.
- 5주차 `DataW5.zip`의 `newfile.txt`와 12주차 `DataW12.zip`의 CSV 3개는 로컬에서 파일 목록을 확인했으며 데이터 복사는 아직 완료하지 않았습니다.
- 지정 폴더에는 별도 Excel 파일이 없었습니다. 10주차 pandas 노트북에서 합성 관측 표를 `rainfall-practice.xlsx`로 생성하고 재읽기 결과를 확인합니다.
- 5·12주차 실습은 위 ZIP의 원본 내용 없이도 실행하도록 연습 데이터를 새로 생성합니다. 합성 자료를 실제 관측으로 해석하지 않습니다.
- PPTX·PDF 강의록과 동영상은 원본 폴더에 유지하며, 실습 자료 저장소에는 복사하지 않았습니다.
- 1·2·7·8·11·15주차는 확인된 별도 실습 파일이 없어 안내용 README만 두었습니다.
