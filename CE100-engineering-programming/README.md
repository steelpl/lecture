# CE100 · 공학프로그래밍입문

**2026학년도 1학기 주차별 실습 자료**입니다. Python의 기본 원리와 기능을 이해해 코딩 AI에 좋은 질문·지시를 하고, 코드와 결과를 검토하는 능력을 기릅니다.

실습 노트북 14개는 **기존 슬라이드가 연결하는 원본 예제와 순서**를 유지하고, 각 구간에 한국어 예측·변형·AI 질문·검토 활동을 덧붙였습니다. [슬라이드 대응표](SLIDE_ALIGNMENT.md)에서 57개 구간의 대응 번호를 확인할 수 있습니다. [학생 학습 가이드](LEARNING_GUIDE.md)에서 진행 방법을, [교수자 가이드](TEACHING_GUIDE.md)에서 수업 운영과 학습 증거 점검 기준을 확인할 수 있습니다.

## 사용 방법

1. 해당 주차 폴더의 README에서 노트북과 준비 사항을 확인합니다.
2. **Colab에서 열기** 링크로 저장소의 노트북을 엽니다. 본인 Drive에 사본을 저장해 실습합니다.
3. **슬라이드 설명 → 결과 예측 → 원본 예제 실행 → 조건 변경 → AI 질문·수정 지시 → 검증** 순서로 진행합니다. 노트북의 S01·S02 구간과 대응 슬라이드 번호를 함께 봅니다.
4. 학생 과제의 TODO를 완성하고 공개 점검에 더해 직접 만든 반례를 확인합니다. “미완료” 출력은 점검 통과가 아닙니다.

## 자료 현황

- 원본 Colab의 예제·변수명·함수명·파일명을 복원했습니다. 원본 코드 320개 중 278개는 그대로이고 42개는 실행 조정을 기록했습니다.
- 원본 Drive 링크, 강의록 파일명, 개편 전·후 해시는 [자료 목록](materials-manifest.json)에 기록했습니다. [슬라이드 대응표](SLIDE_ALIGNMENT.md)에는 기준 PPTX와 대응 구간이 있습니다.
- 5주차는 원본 `newfile.txt`(Line 1~10), 12주차는 원본 `air_pollution.csv`, `rainfall_region.csv`, `groundwater.csv`를 사용합니다. 원본 ZIP과 추출 파일은 각 주차의 `data/` 폴더에 있습니다.
- 같은 ZIP 사본이 해당 노트북 준비 셀에도 포함되어 있습니다. CSV를 합성 자료로 대체하지 않으며, 원본 파일명·기간·지역·단위를 유지합니다.
- pandas는 원본 Titanic 자료와 `titanic.xlsx`, 시각화는 원본 sine·Iris·G1~G5·원그래프 예제로 실습합니다. 공개 데이터셋을 처음 읽을 때 인터넷이 필요합니다.
- 모듈 호출에 필요한 보조 파일은 인터페이스에 맞춰 작성한 실행 보조 예제이며, 원본 파일과 동일하다고 보장하지 않습니다.
- PPTX·PDF 강의록과 동영상 자체는 로컬 원본 폴더에 유지합니다.
- 1·2·7·8·11·15주차는 별도 실습 파일이 확인되지 않아 안내용 README만 두었습니다.
