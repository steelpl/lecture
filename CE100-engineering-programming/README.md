## 사용 방법

1. 해당 주차 폴더의 README에서 노트북과 준비 사항을 확인합니다.
2. **Colab에서 열기** 링크로 저장소의 노트북을 엽니다. 본인 Drive에 사본을 저장해 실습합니다.
3. 외부 데이터·작업 폴더가 필요한 주차는 주차별 안내에 따라 준비합니다.

## 자료 현황

- 노트북은 원본 파일명과 내용을 유지했습니다. 원본 Drive 링크와 원본 강의록의 파일명·슬라이드 번호는 [자료 목록](materials-manifest.json)에 기록했습니다.
- 5주차 `DataW5.zip`의 `newfile.txt`와 12주차 `DataW12.zip`의 CSV 3개는 로컬에서 파일 목록을 확인했으며 데이터 복사는 아직 완료하지 않았습니다.
- 지정 폴더에는 별도 Excel 파일이 없었습니다. 10주차 pandas 노트북에는 Excel 파일 생성·읽기 예제가 포함되어 있습니다.
- PPTX·PDF 강의록과 동영상은 원본 폴더에 유지하며, 실습 자료 저장소에는 복사하지 않았습니다.
- 1·2·7·8·11·15주차는 확인된 별도 실습 파일이 없어 안내용 README만 두었습니다.

## 관리 방식

- `week01`~`week15` 폴더에 주차별 자료를 추가합니다.
- 기존 자료를 가져올 때는 원본 파일명을 유지합니다. 새 파일은 저장소의 주차별 파일명 규칙을 따릅니다.
- 각 주차 README에 실행 링크, 데이터 위치 및 필요한 준비 사항을 함께 기록합니다.
