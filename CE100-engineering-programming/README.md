# CE100 · 공학프로그래밍입문

**주차별 실습 자료**. Python의 원리·기능 이해, 코딩 AI에 대한 질문·지시, 코드·결과 검토 능력 함양

실습 노트북 14개는 **기존 슬라이드가 연결하는 원본 예제와 순서**를 유지하고, 각 구간에 한국어 예측·변형·AI 질문·검토 활동 추가. [슬라이드 대응표](SLIDE_ALIGNMENT.md)에서 57개 구간의 대응 번호를 확인 가능. [학생 학습 가이드](LEARNING_GUIDE.md)에서 진행 방법을, [교수자 가이드](TEACHING_GUIDE.md)에서 수업 운영과 학습 증거 점검 기준을 확인 가능

공통 슬라이드·PDF는 연도 없는 파일명으로 관리. 기존 디자인·페이지 번호와 실습 연결 유지. [학기 운영안내](../CURRENT_OFFERING.md) 참고

휴일·불가피한 일정: 해당 차시 온라인 영상강의 대체. [공통 수업 방침](../TEACHING_POLICY.md) 참고

## 사용 방법

1. 해당 주차 폴더의 README에서 노트북과 준비 사항 확인
2. **Colab에서 열기** 링크로 저장소의 노트북 열기. 본인 Drive에 사본을 저장해 실습
3. **슬라이드 설명 → 결과 예측 → 원본 예제 실행 → 조건 변경 → AI 질문·수정 지시 → 검증** 순서로 진행. 노트북의 S01·S02 구간과 대응 슬라이드 번호 함께 확인
4. 학생 과제의 TODO를 완성하고 공개 점검에 더해 직접 만든 반례 확인. “미완료” 출력은 점검 통과가 아님

## 자료 현황

- 원본 Colab의 예제·변수명·함수명·파일명을 복원. 원본 코드 320개 중 277개는 그대로이고 43개는 실행 조정 기록
- 원본 Drive 링크, 강의록 파일명, 개편 전·후 해시는 [자료 목록](materials-manifest.json)에 기록. [슬라이드 대응표](SLIDE_ALIGNMENT.md)에는 기준 PPTX와 대응 구간이 있음
- 5주차는 원본 `newfile.txt`(Line 1~10), 12주차는 원본 `air_pollution.csv`, `rainfall_region.csv`, `groundwater.csv` 사용. 원본 ZIP과 추출 파일은 각 주차의 `data/` 폴더에 있음
- 같은 ZIP 사본이 해당 노트북 준비 셀에도 포함. CSV를 합성 자료로 대체하지 않으며, 원본 파일명·기간·지역·단위 유지
- pandas는 원본 Titanic 자료와 `titanic.xlsx`, 시각화는 원본 sine·Iris·G1~G5·원그래프 예제로 실습. 공개 데이터셋을 처음 읽을 때 인터넷이 필요
- 모듈 호출에 필요한 보조 파일은 인터페이스에 맞춰 작성한 실행 보조 예제이며, 원본 파일과 동일하다고 보장하지 않음
- 원본 강의록·동영상은 출처 이력으로 보존. 수업용 공통본은 연도 없이 계속 사용
- 1·2·7·8·11·15주차는 별도 실습 파일이 확인되지 않아 안내용 README만 배치
