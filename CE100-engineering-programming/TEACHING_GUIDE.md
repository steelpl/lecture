# 교수자 가이드 · 코딩 AI 사용과 결과 검토

## 수업 목표와 운영

슬라이드로 설명한 개념과 원본 예제를 그대로 실습에 연결하면서, 학생이 입력·출력·조건을 명확하게 표현하고 AI의 제안을 시험과 근거로 검토하도록 안내. 문법을 찾아보는 것을 허용하고 판단 근거를 설명하도록 안내

원본 예제·변수명·함수명·데이터와 순서를 복원. [슬라이드 대응표](SLIDE_ALIGNMENT.md)에서 14개 노트북의 57개 구간 확인. 각 구간에는 슬라이드 번호, 실행 전 예측, 원본 예제, 변형 활동, AI 질문·검토 기록이 있음

한 차시에는 설명한 슬라이드에 대응하는 핵심 구간 선택. 원본 예제 전체가 파일에 들어 있어도 한 번에 전부 진행할 필요 없음. 특히 NumPy 수학 함수·선형대수·분포는 원본 Colab의 선택 확장으로 유지

| 활동 | 운영 예시 | 관찰할 것 |
| --- | --- | --- |
| 슬라이드 개념 설명·예측 | 해당 슬라이드와 S01 같은 구간을 함께 확인 | 예측한 이유를 설명하는가? |
| 원본 예제 실행 | 같은 변수·자료·순서로 따라 실행 | 출력과 원리를 연결하는가? |
| 한 조건 변경 | 값·자료형·축·필터·경계를 하나 변경 | 바꾸기 전 예상과 결과를 비교하는가? |
| AI 질문·수정 지시 | 선택한 구간에서 한 차례 수행 | 입력·출력·조건·반례가 구체적인가? |
| 기능 완성·검토 | 원본 예제의 함수를 완성하고 공개 점검 | 독립된 기대값과 새 반례가 있는가? |

## 학습 증거 점검 기준 예시

아래 다섯 영역을 각각 0~2점으로 관찰 가능. 실제 성적 반영 여부와 비중은 교수자가 정함

| 영역 | 0점 | 1점 | 2점 |
| --- | --- | --- | --- |
| 원리 이해 | 코드의 역할을 설명하지 못함 | 동작은 설명하나 자료형·단위·가정이 빠짐 | 작은 입력을 추적하며 핵심 원리와 조건을 설명 |
| 요구사항·AI 지시 | 목적만 제시 | 입력·출력은 있으나 경계·실패 정책 누락 | 구체적 예·계약·수정 지시를 명시 |
| 구현·실험 | 미완료 또는 재실행만 함 | 공개 점검은 통과하나 변경 실험의 이유 부족 | 계약을 만족하고 입력 변경의 효과를 설명 |
| 결과 검토 | 실행 성공만 근거로 제시 | 공개 시험 결과만 제시 | 독립 기대값을 가진 새 반례와 실제 결과를 제시 |
| 판단·전이 | AI 제안을 근거 없이 채택 | 수정 이유 또는 한계만 설명 | 채택 판단·한계·새 요구사항의 추가 질문을 연결 |

AI 접근 여부나 긴 코드 작성량 자체는 위 점수의 근거가 아님. 원본 예제를 바꾼 사본을 동료와 검토해서도 동일한 판단 근거를 제출 가능. 학생의 추가 시험은 공개 시험을 그대로 반복한 것인지 확인

## 원본과 실행 검증 범위

원본 노트북은 [가져온 시점의 커밋](https://github.com/steelpl/lecture/tree/89e38ea511ab48aab84268d346729a7b1392093a/CE100-engineering-programming)과 원본 Drive 링크로 확인 가능. 기준 PPTX의 실제 발표 순서·키워드 일치·노트북 연결 링크는 사용자 PC 내부에서 분석. 주요 원본·수정 페이지는 이미지로 검토. 슬라이드 코드 이미지 전체의 줄별 대조는 검증 범위 밖. 각 구간은 개념 슬라이드 또는 원본 Colab 실습 구간으로 구분해 연결

원본 코드 셀 320개를 모두 보존해 대응시키고, 설치·경로·버전 호환성·의도된 오류·명백히 잘못된 주석과 표시만 조정. 변경한 셀에는 이유 기록. 원본 예제 대신 별도 관측소/합성 분석 사례를 기본 실습으로 사용하지 않음

5·12주차 데이터는 원본 ZIP과 추출 파일의 바이트가 일치하도록 관리. 원본 자료의 관측 진위나 수집 경위까지 새로 검증했다는 뜻은 아님. 모듈 보조 파일은 원본이 제공되지 않아 동일한 호출 인터페이스를 지원하도록 작성했으며 이 차이를 표시

14개 노트북을 각각 독립 Python 프로세스에서 순차 실행. 원본 예제 확인, 과제 참고 구현의 공개 점검 통과, 대표 오답의 검출, 파일·Excel 입출력, 그래프 그리기, 원본 데이터 일치 확인. 입력 실습은 정상값 2를 제공해 기본 경로 검증. 학생용 TODO는 미완성으로 남기고 출력·실행 번호를 비움

Colab 웹 UI의 Drive 인증·업로드 조작은 별도로 미시험. 검증용 Linux 환경에는 NanumGothic이 없어 일부 한글 표시 경고가 발생 가능하며, Colab 준비 셀은 원본과 같은 한글 폰트를 설치·등록하도록 구성. 실제 수업 전 Colab 환경에서 폰트·입력·Drive 실습 확인
