# 실습 학습 가이드

이 과목은 Python의 기본 원리와 기능을 이해해 **코딩 AI에 좋은 질문과 지시를 하고, 생성된 코드와 결과를 검토하는 능력**을 기르는 것을 목표로 합니다. 문법을 찾아보면서 풀어도 됩니다. 자신이 요구한 동작과 결과가 맞는 이유는 설명할 수 있어야 합니다.

## 실습에서 남길 다섯 가지 근거

| 능력 | 학생이 남기는 근거 |
| --- | --- |
| 기본 원리 이해 | 핵심 코드 한 줄의 역할, 입력 자료형·구조·단위 설명 |
| 문제 구체화 | 입력·출력 예, 포함·제외 조건, 잘못된 입력 처리 정책 |
| 질문과 지시 | 최초 요청, 모호한 조건을 보완한 수정 요청 |
| 결과 검토 | 손계산·작은 표·기대값에 기반한 정상·경계·실패 시험 |
| 적용 범위 판단 | 확인한 조건과 아직 확인하지 않은 조건, 새 상황에서 필요한 추가 질문 |

## 노트북 진행 순서

1. **원리:** 오늘 필요한 개념과 데이터의 의미를 읽습니다.
2. **예측:** 코드 실행 전에 출력이나 변화를 예상하고 이유를 적습니다.
3. **실험:** 예제를 실행한 뒤 입력·조건을 하나 바꾸고 예상과 실제 결과를 비교합니다.
4. **기능 완성:** TODO의 입력·출력·실패 조건을 읽고 처리 단계를 쓴 뒤 함수를 완성합니다.
5. **검토와 지시:** 가상 AI 답변의 오류를 반례로 드러내고, 실제 요청문과 수정 지시를 작성합니다.
6. **전이:** 요구사항이 바뀐 상황에서 무엇을 다시 확인해야 할지 설명합니다.

노트북의 가상 AI 답변은 검토용으로 작성한 예시입니다. AI가 항상 같은 오류를 낸다는 의미는 아닙니다. AI 도구를 이용하기 어려우면 이 예시를 동료와 검토하고 같은 요청문·검증 기록을 작성합니다.

## AI에게 질문하는 방법

처음에는 개념 설명이나 다음 단계의 힌트를 요청해도 됩니다. 구현을 요청할 때는 아래 내용을 채웁니다. 모호한 항목이 남아 있으면 AI에게 먼저 질문하게 합니다.

```text
목적과 환경: Google Colab의 Python에서 무엇을 하려는가?
입력: 자료형, 표의 열 이름, 배열의 행·열 의미, 단위, 작은 입력 예는?
출력: 자료형과 구조, 순서, 단위, 정상 입력의 기대 결과는?
조건: 포함·제외 기준, 결측값, 빈 입력, 잘못된 입력을 어떻게 다룰 것인가?
제약: 원본 데이터 보존, 허용 라이브러리, 작업할 경로 등의 조건은?
검증: 정상 예, 경계 예, 잘못된 입력에서 기대하는 결과 또는 예외는?
먼저 불명확한 조건과 처리 계획을 설명하고, 그 뒤 코드와 검증을 제시해 줘.
```

예를 들어 “평균을 구해 줘”를 다음과 같이 구체화할 수 있습니다.

> 입력은 mm 단위의 유한한 비음수 숫자 리스트다. 산술평균을 숫자로 반환하고 입력을 바꾸지 않는다. 빈 리스트와 음수 포함 입력은 ValueError로 거절한다. `[0, 2, 4]`의 결과는 2이고 `[0, 0]`의 결과는 0이다. 먼저 실패 조건과 처리 순서를 설명해 줘.

오류를 질문할 때는 실행 환경, 최소 재현 코드, 기대 결과, 실제 출력·오류 메시지, 이미 확인한 조건을 함께 제시합니다. AI의 설명을 이해하기 어렵다면 “이 작은 입력을 한 줄씩 추적해 달라”고 요청합니다.

## 결과를 검토하는 방법

- **예상값을 먼저 정합니다.** 작은 입력은 손으로 계산하고, AI가 제시한 기대값도 직접 확인합니다.
- **다른 종류의 입력을 시험합니다.** 정상 예 외에 0, 빈 입력, 경계값, 형식 오류, 결측, 서로 길이가 다른 축 등을 과제 계약에 맞게 선택합니다.
- **중간 결과를 확인합니다.** 선택된 행, 배열 shape, 저장한 파일의 재읽기 결과, 그래프의 실제 좌표를 확인합니다.
- **독립된 근거를 사용합니다.** 같은 코드를 두 번 실행하는 것 외에 손계산·다른 표현의 계산·입출력 왕복 검증을 사용합니다.
- **결론의 범위를 적습니다.** 공개 시험 통과는 모든 입력에서의 정답 보장이 아닙니다. 시험하지 않은 형식이나 실제 자료에 대한 가정도 기록합니다.

## 실행과 파일

Colab 링크로 열고 본인 Drive에 사본을 저장합니다. 예제와 공개 점검은 위에서 아래로 실행하며, 수정 뒤에는 런타임을 다시 시작해 전체 순서로 확인합니다.

TODO는 처음에 `NotImplementedError`를 내도록 되어 있습니다. 공개 점검 셀이 이를 잡아 **“미완료”**라고 표시합니다. 이는 실행 준비가 된 학생용 배포본이라는 뜻이며, 과제 통과가 아닙니다. 함수를 완성한 뒤 점검을 다시 실행하고 자신의 반례를 추가합니다.

- 예제 데이터는 합성 데이터이며, 파일 실습은 임시 폴더를 사용합니다. 원본 로컬 ZIP이나 개인 Drive 경로를 준비할 필요가 없습니다.
- NumPy·pandas·Matplotlib은 해당 노트북에서 불러옵니다. Excel 예제에는 `openpyxl`도 필요합니다. 없다면 Colab의 별도 셀에서 `%pip install openpyxl`을 실행합니다.
- Excel 실습 파일은 10주차 노트북에서 생성합니다. 출력된 경로의 파일을 Colab 파일 패널에서 다운로드해 표와 비교할 수 있습니다.
- 원본 강의 자료의 링크와 개편 전·후 해시는 `materials-manifest.json`에 남깁니다.

## 제출 기록 예시

```text
1. 내 예측과 근거:
2. 바꿔 본 입력·조건과 관찰:
3. 완성한 함수와 핵심 원리 설명:
4. 최초 AI 요청과 수정 요청:
5. 새로 추가한 시험: 입력 / 기대값 / 실제값 / 기대값을 정한 근거
6. 채택·수정·거절한 제안과 이유:
7. 아직 확인하지 못한 조건과 새 상황에서 할 질문:
```
