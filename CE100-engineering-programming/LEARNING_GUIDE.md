# 실습 학습 가이드

목표: Python의 원리·기능 이해를 바탕으로 **코딩 AI에 좋은 질문·지시를 하고 코드·결과를 검토하는 능력** 함양. 문법 검색 허용. 요구한 동작과 결과의 타당성을 설명할 수 있는 수준 지향

## 실습에서 남길 다섯 가지 근거

| 능력 | 학생이 남기는 근거 |
| --- | --- |
| 기본 원리 이해 | 핵심 코드 한 줄의 역할, 입력 자료형·구조·단위 설명 |
| 문제 구체화 | 입력·출력 예, 포함·제외 조건, 잘못된 입력 처리 정책 |
| 질문과 지시 | 최초 요청, 모호한 조건을 보완한 수정 요청 |
| 결과 검토 | 손계산·작은 표·기대값에 기반한 정상·경계·실패 시험 |
| 적용 범위 판단 | 확인한 조건과 아직 확인하지 않은 조건, 새 상황에서 필요한 추가 질문 |

## 노트북 진행 순서

1. **슬라이드 연결:** [대응표](SLIDE_ALIGNMENT.md)와 노트북의 S01·S02 구간에서 오늘 설명한 슬라이드 번호 찾기
2. **예측:** 코드 실행 전에 출력이나 변화를 예상하고 이유 기록
3. **실험:** 슬라이드가 연결하는 원본 예제를 실행한 뒤 같은 변수·함수·자료에서 조건을 하나 바꾸고 예상과 실제 결과 비교
4. **기능 완성:** TODO의 입력·출력·실패 조건을 읽고 처리 단계를 쓴 뒤 함수 완성
5. **검토와 지시:** 원본 예제에 관한 AI 요청문을 작성하고, 제안받은 변경을 반례로 검토해 수정 지시 작성
6. **전이:** 요구사항이 바뀐 상황에서 무엇을 다시 확인해야 할지 설명

수업에서 지정한 구간을 중심으로 기록. 모든 예제에서 별도의 AI 대화 반복은 선택. AI 도구를 이용하기 어려우면 원본 예제를 바꾼 사본을 동료와 검토하고 같은 요청문·검증 기록을 작성. 원본과 바꿔 본 사본은 구분

## AI에게 질문하는 방법

개념 설명·다음 단계의 힌트부터 요청 가능. 구현 요청 시 아래 항목 명시. 모호한 조건은 AI에게 먼저 질문 요청

```text
목적과 환경: Google Colab의 Python에서 무엇을 하려는가?
입력: 자료형, 표의 열 이름, 배열의 행·열 의미, 단위, 작은 입력 예는?
출력: 자료형과 구조, 순서, 단위, 정상 입력의 기대 결과는?
조건: 포함·제외 기준, 결측값, 빈 입력, 잘못된 입력을 어떻게 다룰 것인가?
제약: 원본 데이터 보존, 허용 라이브러리, 작업할 경로 등의 조건은?
검증: 정상 예, 경계 예, 잘못된 입력에서 기대하는 결과 또는 예외는?
먼저 불명확한 조건과 처리 계획을 설명하고, 그 뒤 코드와 검증을 제시해 줘.
```

예를 들어 원본 `sort_strings`의 “문자열을 정렬해 줘”를 다음과 같이 구체화 가능

> 입력: 문자열 리스트. 출력: 오름차순 정렬한 새 리스트. 원본 보존, 빈 리스트 허용. 문자열 하나는 TypeError로 거절. `["World", "Hello"]` → `["Hello", "World"]`. `"Hello World"`의 글자별 정렬은 요구사항에 미포함. 두 입력의 차이·처리 계획부터 설명 요청

오류를 질문할 때는 실행 환경, 최소 재현 코드, 기대 결과, 실제 출력·오류 메시지, 이미 확인한 조건을 함께 제시. AI의 설명을 이해하기 어렵다면 “이 작은 입력을 한 줄씩 추적해 달라”고 요청

## 결과를 검토하는 방법

- **예상값 사전 설정.** 작은 입력은 손으로 계산하고, AI가 제시한 기대값도 직접 확인
- **다른 종류의 입력 시험.** 정상 예 외에 0, 빈 입력, 경계값, 형식 오류, 결측, 서로 길이가 다른 축 등을 과제 계약에 맞게 선택
- **중간 결과 확인.** 선택된 행, 배열 shape, 저장한 파일의 재읽기 결과, 그래프의 실제 좌표 확인
- **독립된 근거 사용.** 같은 코드를 두 번 실행하는 것 외에 손계산·다른 표현의 계산·입출력 왕복 검증 사용
- **결론의 범위 기록.** 공개 시험 통과는 모든 입력에서의 정답 보장이 아님. 시험하지 않은 형식이나 실제 자료에 대한 가정도 기록

## 실행과 파일

Colab 링크로 열고 본인 Drive에 사본 저장. 예제와 공개 점검은 위에서 아래로 실행하며, 수정 뒤에는 런타임을 다시 시작해 전체 순서로 확인

TODO는 처음에 `NotImplementedError`를 내도록 구성. 공개 점검 셀이 이를 잡아 **“미완료”**라고 표시. 이는 실행 준비가 된 학생용 배포본이라는 뜻이며, 과제 통과가 아님. 함수를 완성한 뒤 점검을 다시 실행하고 자신의 반례 추가

- 5·12주차는 원본 `DataW5.zip`·`DataW12.zip`의 실제 파일 사용. 저장소의 각 주차 `data/` 폴더와 노트북 준비 셀에 같은 ZIP 사본이 있어 별도 다운로드 없이 준비 가능
- 기본 작업 폴더는 임시 폴더. 슬라이드의 Google Drive 연결·업로드 자체를 연습할 때는 `USE_GOOGLE_DRIVE`·`REQUEST_UPLOAD` 선택. 파일명과 핵심 계산은 동일
- 6주차 모듈의 실행 보조 파일은 원본 `mod1`·`my_package` 호출을 지원하도록 작성한 예제. 원본 보조 파일과 내용이 동일하다고 표시하지 않음
- 최신 Colab 런타임을 기준. 로컬 실행에서는 Matplotlib 3.10 이상 사용
- NumPy·pandas·Matplotlib·Seaborn은 해당 노트북에서 불러오기. Excel에는 `openpyxl`, HTML 표 읽기에는 `lxml`도 필요. 없다면 Colab의 별도 셀에서 `%pip install openpyxl lxml` 실행
- 원본 Titanic·Iris·tips 데이터셋은 공개 URL에서 읽으므로 첫 다운로드에는 인터넷이 필요
- Excel 실습은 원본과 같은 `titanic.xlsx`를 생성·재읽기. 작업 폴더에서 다운로드해 원본 표와 비교 가능
- 예상한 오류를 관찰하는 예제는 유지하되 전체 실행을 막던 오류는 처리 방식과 이유를 표시. 예외 처리 노트북은 먼저 정상 입력 `2`로 실행한 뒤 잘못된 입력을 구간별로 시험
- 원본 강의 자료의 링크와 개편 전·후 해시는 `materials-manifest.json`에 기록
