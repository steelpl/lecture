# 슬라이드 가독성 개선 기록

학생용 자료는 각 과목의 주차별 실습에서 안내. 이 폴더의 과거 페이지 번호·설계 좌표·수정 이력은 교수자 참고용

- 기존 남색·금색 틀과 유효한 그림·수식·예제 보존
- 긴 글머리표로 대체했던 103쪽 검토: 75쪽을 코드·입출력·표·그래프·중간 계산으로 구성, 28쪽은 중복 내용 정리
- 모든 파일에 붙였던 실습 관리 페이지 84쪽 제거, 그 밖의 반복 설명 3쪽 정리
- 학생 화면의 과거 노트북 안내·PPT 대응 번호·구간 ID 제거. 필요한 현재 실습 링크만 유지
- 문제·조건·요구사항은 완결된 문장, 풀이·해설은 짧고 자연스러운 한국어 유지
- 학습 공통본은 연도 없는 로컬 폴더에서 관리. 학기 날짜는 별도 운영안내로 제공
- PPTX만 갱신. PDF는 별도 요청 후 변환

`spring-design.json`은 이번 검토의 개별 설계 기록. 매년 실행하는 재생성 도구가 아님. 현재 로컬 PPTX가 편집 기준이며, 내용이 바뀐 파일만 검수·갱신

그림은 직접 계산한 예제에서 작성. 희소 비율은 불량 2개/100개, Taylor·선형계·Ralston 예제는 수업의 입력과 중간값으로 확인
