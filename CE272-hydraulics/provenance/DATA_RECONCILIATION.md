# 원본 자료·계산 대조

원본은 해시와 함께 보존. 새 실습에서 식·참조·가정을 드러내고 정리본과 대조

| 대상 | 원본에서 확인한 내용 | 새 실습의 처리 |
| --- | --- | --- |
| 비에너지 Excel, 두 시트 C2:C495 | q=1.5 곡선이 수심 A열 대신 q=1 비에너지 B열 참조 | 같은 행의 수심으로 `E=y+q²/(2gy²)` 계산. 원본 참조식도 비교 곡선으로 재현 |
| 예제 4.6 난류 표 | u·v 관측열의 합·평균·변동이 인쇄된 집계열과 불일치. 시간 16초 중복·12초 누락 등 시간표도 불일치 | 관측열 불일치와 과거 계산은 교수자 기록에 보존. 학생용 문제는 밀도·유속 경사·속도변동 곱의 평균을 명시한 일관된 조건으로 구성. 의도한 관측값을 임의 추정하지 않음 |
| Step Method의 Standard K6:K10 | 두 단면 평균 마찰경사에서 두 행 앞을 참조 | 바로 앞 단면과 현재 단면의 평균 사용 |
| 같은 시트 N6:N10 | 기준 전수두도 두 행 앞을 참조 | 바로 앞 단면 전수두에 해당 구간 마찰손실 합산 |
| Standard_prac의 빈칸 | 학생 작성용 미완성 영역 | 오류로 분류하지 않음. 신규 실습의 직접 작성 항목과 구분 |
