# 계산 도구·가정

[hydraulics.py](hydraulics.py)의 식·입력·반환값·범위 확인. 함수 문법 암기보다 식과 조건의 연결에 집중

| 계산 | 기준 | 확인할 가정 |
| --- | --- | --- |
| Darcy 마찰계수 | 층류 64/Re, 난류 Colebrook 잔차의 근 | 원본 관수로 기준 Re<2100·Re>4000. 천이영역은 단일 f 확정 중단 |
| 관 손실 | `(fL/D+ΣK)V²/(2g)` | Darcy/Fanning 구분, K의 기준속도·조도 단위 |
| 유량 근찾기 | 에너지 잔차·난류 구간 | 출구 속도수두는 `exit_coefficient`, 실제 국부손실과 구분 |
| Hardy Cross | 전역 유량·회로 행렬·고정 f | 공유관 부호·초기 절점 연속식·회로 수두잔차 |
| Manning | `Q=A Rh^(2/3)√S0/n` | 정상 등류·SI 단위·조도 적용 범위 |
| 한계수심 | `Fr²=Q²T/(gA³)=1` | 직사각형의 `yc=(q²/g)^(1/3)`와 일반 단면 구분 |
| 원형 개수로 | 젖은 중심각 θ, 고정 n·경사 | 라디안, 자유수면, 최대 Q와 최대 V의 차이 |
| 비력·도수 | 운동량 함수·공액수심 | 외력·압력분포·손실 조건, 비에너지 보존과 구분 |
| 직접축차 | 인접 단면의 평균 Sf·에너지식 | 상류 방향 거리, 한계·등류수심 경계 구간 분리 |
| 표준축차 | 같은 에너지 잔차의 근 | 제공 함수는 원본 M1용. 다른 수면형은 경계·방향·근의 가지 재설정 |
| 상사비 | 모든 비 원형/모형 | 지배력·물성·시간비·축척 효과 |

계산기는 알려진 가정 아래의 교육용 모형. 실제 수리 설계의 검토 범위·자료를 대신하지 않음
