# 수리학 실습 방법

목표: 관수로·개수로·상사의 원리 이해와 지식 심화. 코드·Excel은 식과 조건을 계산·비교하는 도구

1. 슬라이드의 문제·기호·기준면·경계조건 확인
2. 단위·보존식·가정 정리, 작은 손계산과 결과 예측
3. Colab 또는 Excel에서 계산. 결과와 중간값을 손계산에 연결
4. 입력 한 가지 변경. 고정한 조건과 다시 계산한 계수 구분
5. 단위·연속식·에너지·운동량·유효 범위로 검토
6. 차이의 원인·적용 한계·자신의 설명 기록

한 번에 바꿀 입력과 유지할 가정을 먼저 정함. 천이영역·한계수심·등류수심 근처에서는 식의 범위와 근의 가지부터 재검토

원본 예제·개념 적용의 추가 조건·공식 재현점 구분. 원본 Excel의 표시값·셀 참조 문제는에서 확인

AI 활용은 개념 학습 후 선택 활동. 자신의 손계산·보존식·반례로 설명과 계산을 검토하고 수정 근거 기록

핵심 산출물: 예측·손계산, 식과 코드의 연결, 조건 변경 비교, 보존식 검산, 모형·수치·관측 오차 설명
