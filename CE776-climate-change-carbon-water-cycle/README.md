# CE776 · Climate Change and Carbon/Water Cycle

A graduate course on climate and carbon/water cycles through observations, models and statistics.

Learning goal: define a research question → select suitable data and methods → reproduce the calculation → explain assumptions and limitations.

[Course information](CURRENT_OFFERING.md) · [Study guide](STUDY_GUIDE.md) · [Earth Engine setup](GEE_SETUP.md) · [Data sources](DATA_SOURCES.md)

Practice is provided only for the sessions listed above. Python basics are optional. The quantile-regression notebook is an alternative to Excel Solver; completing both is unnecessary.

Start with the question, inputs and task in each activity. Explain how the results relate to the concept and its assumptions.

Lecture PPTX files are maintained in the local common-materials folder. Class dates, times and deadlines are managed separately. Observation and publication years remain unchanged.
