# 교수자 가이드

학생 화면은 현재 개념·예제·실습 열기에 집중. 과거 자료 대응·수정 근거·검수 기록은 [관리 기록](provenance/)에서 확인

- 실습의 중심: 자료·확률·행렬·최적화·학습 알고리즘의 원리와 결과 해석
- 프로그래밍·AI 도입: 입력·조건·산출물·시험 예를 구체화하는 기초 역량
- 통계 복습: 필요한 부분 선택. 상세 분포·검정은 후속 확률·모형 학습의 참고
- 수락기각·MCMC: 정규화 여부·제안분포·난수·수렴과 혼합을 구분
- 신경망: 순전파·미분·한 번의 갱신을 설명한 뒤 반복 학습
- CNN: 두 장의 예제 적합을 일반적인 인식 성능으로 해석하지 않도록 지도
- 각 학기 일정은 운영 설정만 갱신. 내용 수정이 필요한 파일만 PPTX·실습 검수
- PDF 변환은 별도 요청 후 일괄 진행
