# 자료 출처

- 포유류 수면 자료 `msleep.csv`: 기존 수업 입력 자료, ggplot2의 msleep 자료. 하루 수면시간·체중 등 종별 관측
- 행복도 자료 `2019.csv`: World Happiness Report 2019의 수업용 CSV. 관측 연도는 자료의 의미에 포함
- 확률·상자·두 봉우리 함수·행렬·신경망 수치 예: 담당 교수 수업 예제
- 당뇨병·붓꽃: scikit-learn 내장 자료. 노트북에서 설명·분할 조건 확인
- O·X 영상과 두 ReLU 경로의 예제: Josh Starmer, *The StatQuest Illustrated Guide to Neural Networks and AI* 및 [StatQuest 공개 예제](https://github.com/StatQuest/signa). 설명·구현은 본 과목의 간결한 실습 형태로 작성

공유 입력 자료는 실제 사용하는 두 CSV만 배포. 관측 연도·출처의 실제 연도 보존. 수정 근거와 원본 파일 해시는 [교수자 관리 기록](provenance/)에 보관
