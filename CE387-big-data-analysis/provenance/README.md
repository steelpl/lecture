# 교수자 관리 기록

학생용 실습과 구분한 원본·수정·검수 기록. 원본 강의 파일은 로컬에 보존

- PPTX: 28개, 910페이지 원본 → 907페이지 공통본
- 원본의 그림·미디어·수식 구성 보존, 실제 오류·낡은 설명만 선별 수정
- 과거 하드웨어 가격·출처 불명 AI 일화·과도한 학습법 단정 3페이지 제외
- 수업 연도·달력 날짜 제거, 학기 운영안내 한 곳으로 연결
- 과거 Colab 링크는 현재 자료로 갱신. 대응 슬라이드 번호·개편 구분은 학생 화면에 표시하지 않음
- 베이즈 반올림·가상 검사 조건·직교투영·대칭 늘이기·신경망 기울기·ReLU 양의 배율 조건·PCA 중심화 계산 수정
- Excel: 기존 4개 파일의 형식·수식 구조 보존. 신경망 미분은 활성화 전 값으로 조건 판단
- 매크로: 정적 검토. 셀 반복 계산·값 기록만 사용, 자동 실행·외부 파일·네트워크·프로세스 호출 없음. 검수 계산은 매크로 비활성 상태에서 실행
- 전체 PPTX를 PowerPoint에서 열고 이미지로 렌더링. PDF 변환 없음

최종 검수: PPTX 28개·907페이지를 PowerPoint에서 열고 전체 렌더링. 개별 개선 28페이지 화면 확인, 새 텍스트 넘침 0. 현재 노트북 링크 44개와 숨김 절 이동 대상 확인. 원본 강의 파일·미디어 바이트 보존

실습: 노트북 16개·코드 셀 68개 실행, 오류 0. 네 Excel 파일을 데스크톱 Excel에서 재계산. 수락기각 후보 900개·MCMC 전이 5,000회·신경망 순전파와 두 조건의 여섯 기울기 확인. 매크로 실행 없음
