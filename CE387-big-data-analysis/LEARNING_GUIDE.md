# 학습 방법

작은 수치 예를 설명할 수 있는 것이 출발점. 코드를 암기하기보다 입력·중간 계산·출력의 의미를 연결

1. 문제의 자료·단위·조건 확인
2. 작은 예의 결과를 손계산하거나 실행 전에 예측
3. 주어진 코드·Excel 수식의 각 단계 확인
4. 조건 하나를 바꾸어 결과 비교
5. 차이가 생긴 이유·모형의 가정·적용 한계 설명

AI에 구현을 맡길 때는 자료 구조·수학적 조건·출력 형식·작은 시험 예를 함께 전달. 결과는 손계산·독립된 계산법·경계 사례로 검토. AI 사용 자체를 모든 실습의 목표로 삼지 않음

실행 순서: Colab 열기 → 런타임 연결 → 위에서 아래로 실행. 재실행 때 난수·변수 상태에 유의. 노트북 문서 저장과 런타임의 변수 보관은 별개

Excel F9는 난수 재추출. 다른 결과가 나와도 함수·조건·분포의 특징을 기준으로 비교. 신경망 Excel은 셀 수식만으로도 핵심 계산 확인 가능

연습문제는 완결된 문장, 풀이·결과 설명은 짧고 자연스러운 단문. 날짜·평가 일정·허용 도구는 학기 운영안내 확인
