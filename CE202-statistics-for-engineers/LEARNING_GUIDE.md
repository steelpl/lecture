# 통계 실습 진행 방법

목표: 자료·확률·분포·추정·검정의 원리 이해와 통계적 해석 심화

코드·Excel의 역할: 정의에 따른 계산·분포 시각화·표본 조건 비교. 패키지 호출 결과를 통계적 가정·해석과 연결

1. 슬라이드의 문제·입력·단위·가정 확인
2. 작은 예제 손계산과 실행 전 예측
3. Colab·Excel의 계산식·중간값·그래프를 원리와 연결
4. 한 조건만 바꾼 뒤 기준 결과와 비교
5. 분모·자유도·꼬리·표본 조건의 영향과 통계적 의미 설명
6. 해석·적용 조건·한계를 자신의 말로 기록

핵심 기록: 문제와 가정 / 손계산·예측 / 기준 계산 / 변경 비교 / 개념 설명 / 한계

선택 심화: 개념 학습 후 AI 설명·계산·코드 검토. AI 사용이나 요청문 제출 없이도 본 실습의 핵심 학습 완료 가능. AI 사용 시 입력·조건을 명시하고 별도 검산 근거 기록

연습문제: 상황·요구사항을 완결된 문장으로 제시. 풀이·해설·기록 양식은 자연스러운 단문 사용

None 항목은 직접 작성. 입력을 바꾼 경우 기대값도 원리·독립 계산으로 다시 확인. 기존 확인문을 무작정 삭제하지 않음
