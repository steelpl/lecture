# 교수자 안내

통계량·확률·추론의 의미를 손계산과 계산표로 확인. 코딩 숙련보다 가정과 결과 해석에 집중

실습 선정은 [practice-plan.json](practice-plan.json)에서 관리. 필요한 개념만 실습으로 연결하며, 복습·평가·개념 설명 주차에 파일을 일괄 추가하지 않음

슬라이드의 문제·수치·기호와 실습의 입력 일치 확인. 학생에게는 실제 활동의 이름으로 연결하고 과거 자료와의 대응 번호는 표시하지 않음

이전 생성 자료는 provenance/previous-materials에 보관. 현재 학생 실습으로 연결하지 않음. 원본 강의 자료는 수정하지 않음
