# 수업 운영·검토 가이드

슬라이드 설명과 같은 예제를 도구로 확인하는 병행 구성. 문법 암기보다 통계 질문·입력·모형·출력·검증에 집중

- 시연: 슬라이드 예측 → 작은 손계산 → 도구 계산. 답보다 분모·단위·조건의 선택 근거 질문
- 실습: 변경 셀에서 한 조건만 수정. 원본과 변형 결과 비교
- 선택 심화: 개념 학습 후 AI 설명·계산의 오류 점검. 사용 여부보다 통계 원리·가정·해석의 근거 확인
- 확인: 공개 계산·개념 체크, 가정·불확실성·해석은 서술 검토. 임의의 글자 수 기준 채점 없음
- 평가 반영 기준: 원본 중간40%·기말40%·퀴즈10%·출석10% 유지. 신규 실습을 별도 평가 비중으로 임의 추가하지 않음
- 휴일·불가피한 일정: 모든 과목에서 해당 차시의 온라인 영상강의 대체. 5/13 추정 (4), 5/18 가설검정 (1)
- 통계적 판단: 기각 못함과 H0 입증의 구분, 반복 관측의 독립성, 희소 비율 Wald 구간의 한계, 고전 ANOVA와 Welch의 모형 구분
- 교차 도구 검토: 정의가 같은 값끼리 대조. 분위수·첨도·표본분산·회귀 MSE의 정의 차이 별도 설명

원본 데이터 4개 보존. ANOVA 정리본의 기계6 값은 슬라이드18·jamovi·원본 Excel 저장 결과에 따른 선택. [자료 대조 기록](DATA_RECONCILIATION.md) 참고

2027 슬라이드의 기존 틀·순서·페이지 번호 유지. 시험 좌석배정의 개인 명단 제거 후 평가 준비 안내로 교체

실습 설계: 질문·가정 확인 → 손계산·예측 → 계산·시각화 → 한 조건 변경 → 통계적 해석·한계 설명. 알고리즘·계산식을 읽고 중간값과 원리를 연결. 학생의 핵심 산출물은 예측·손계산·변경 비교·개념 설명·적용 한계

연습문제의 문제·요구사항은 완결된 문장으로 작성. 풀이·해설은 단문 유지. AI 요청문 작성·에이전트 구축·프롬프트 품질을 필수 과제로 일괄 지정하지 않음
