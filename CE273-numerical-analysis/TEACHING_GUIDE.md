# 수업 운영·검토 가이드

슬라이드의 설명과 같은 예제를 실제 도구로 확인하는 병행 구성. 코드 암기보다 입력·처리·갱신·반환·검증의 의미에 집중

- 시연: 슬라이드 예측 → 작은 손계산 → Colab·Excel 실행 → 기준값 대조
- 실습: 한 조건만 변경. 입력 차이·알고리즘 차이·반올림 차이 분리
- 선택 심화: 개념 학습 후 AI 구현·설명의 오류 점검. 사용 여부보다 갱신식·오차·수렴·검산 근거 확인
- 평가: 원본 과제20%·퀴즈10%·중간30%·기말30%·출석10% 유지. 새 실습을 별도 비중으로 임의 추가하지 않음
- 과제: 6·13주차 배치 유지. 퀴즈: 4·7·11·15주차 첫 차시 배치 유지. 실제 제출 시각·운영은 학기 공지
- 휴일·불가피한 일정: 해당 차시 온라인 영상강의 대체
- 검산: 참값이 있는 예제는 참오차, 없는 문제는 잔차·갱신량·방법 간 일치와 조건수·가정 함께 검토
- 종료: 반복 횟수 상한 도달을 수렴 성공으로 처리하지 않음. 위치와 함수 잔차의 단위·허용오차 구분
- 비교: 가위치법의 실제 함수값과 Illinois 가중값, 한 번 교정 Heun과 반복 교정, Ralston의 계수 변형 구분
- 학습 증거: 공개 계산·개념 확인과 서술 검토 분리. 임의의 글자 수 기준 자동 채점 없음

원본 영문 기술 용어·핵심 수식·차시 순서 유지. 새 설명·지시는 짧고 자연스러운 한글 사용. 수정한 수식·설명은 [개편 기록](provenance/README.md)과 원본 페이지로 추적

[자료 대조 기록](provenance/DATA_RECONCILIATION.md) 참고. 기존 Colab 원본은 변경 없이 유지, 새 실습에서 비교 기준·종료 조건·실패 보고 보완

실습 설계: 모형·가정 확인 → 손계산·첫 갱신 → 단계별 계산 → 스텝·초기값 변경 → 오차·수렴·안정성 설명. 알고리즘·계산식을 읽고 중간값과 원리를 연결. 학생의 핵심 산출물은 예측·손계산·변경 비교·개념 설명·적용 한계

연습문제의 문제·요구사항은 완결된 문장으로 작성. 풀이·해설은 단문 유지. AI 요청문 작성·에이전트 구축·프롬프트 품질을 필수 과제로 일괄 지정하지 않음
