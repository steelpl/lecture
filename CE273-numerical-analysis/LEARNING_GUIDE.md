# 수치해석 실습 진행 방법

목표: 수치 원리·도구 기능 이해, 좋은 AI 질문·지시, 오차·수렴·결과를 검토할 기본 역량

1. 슬라이드에서 문제·모형·입력·단위·가정 확인
2. 방향·대략값·분모·초기조건·종료 기준 예측. 작은 입력은 손계산
3. Colab에서 위에서 아래로 실행. Excel·해석해·다른 방법과 대조
4. 원본 셀 복사 후 스텝·초기값·입력·방법 중 한 조건씩 변경
5. AI에 목적·입력·알고리즘·출력·허용오차·실패 조건을 포함한 요청
6. 실행값·오차·잔차·수렴 상태·한계 검토. 채택·수정·거절의 근거 기록

AI 요청 예: “선형 항력 낙하산 모형. m=68.1kg, c=12.5kg/s, g=9.81m/s², v(0)=0. Euler h=2s로 t=10s까지 계산. 모든 중간값·단위·해석해와의 오차 제시. h를 바꿀 때 종료점은 유지. 입력 검증과 실패 상태도 설명.”

결과 검토의 기준:

- 입력·정의·단위·dtype·자료 순서의 일치
- 스텝·구간·초기값·알고리즘 계수·종료 기준의 일치
- 해석해·원식 대입·보존식·독립 라이브러리 등 별도 근거
- 참오차·갱신량·잔차·해 오차의 차이, 조건수·수렴·실패 상태
- 표시 자릿수·반올림 입력·도구 기본값의 영향

None 항목과 변경 셀은 직접 작성. 공개 계산 확인 통과만으로 모형·해석의 타당성 보장 불가. AI 없이 핵심 원리 한 가지를 설명하고 실제 검산 근거 제시

Colab 권장. 로컬 Jupyter 사용 시 Python 3.11 이상, 노트북에 안내된 패키지 버전 필요. 그래프의 영문 축 표기는 폰트 설치 없이 재현하기 위한 선택. 원본 용어와 단위 대조

Excel: 다운로드 후 자동 계산 사용. 옅은 파랑 셀은 입력, 흰 셀은 계산식. 입력 허용 범위·분할 조건 확인. 범위를 벗어난 변경이나 행 추가·삭제는 식의 적용 조건부터 재검토

원본 비교 답안은 14주차 solutions 폴더에 별도 보관. 먼저 예측·계산·검토 기록 후 결과 대조
